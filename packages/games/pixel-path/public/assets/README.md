# Pixel Path Assets

This directory should contain:

## Audio Files

### Music Tracks
- `/assets/audio/music-calm.mp3` - Background music for tutorial levels
- `/assets/audio/music-upbeat.mp3` - Background music for easy levels
- `/assets/audio/music-intense.mp3` - Background music for medium/hard levels

### Sound Effects
- `/assets/audio/sfx-draw.mp3` - Sound when drawing a path
- `/assets/audio/sfx-erase.mp3` - Sound when erasing a path
- `/assets/audio/sfx-goal.mp3` - Sound when reaching the goal
- `/assets/audio/sfx-fail.mp3` - Sound when failing a level
- `/assets/audio/sfx-click.mp3` - UI click sound

## Notes

Audio files are not included in the repository. You can:
1. Use placeholder audio files for development
2. Replace with actual game audio later
3. The game will work without audio files (AudioManager handles missing files gracefully)
